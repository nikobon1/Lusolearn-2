# Изменения структуры базы (Supabase)

Скрипты в `migrations/` запускаются вручную, один раз, по порядку:

1. Откройте Supabase → проект → **SQL Editor** → **New query**.
2. Вставьте содержимое файла и нажмите **Run**.

Скрипты можно безопасно запускать повторно.

| Файл | Что делает |
|---|---|
| `20261125_review_logs.sql` | Журнал повторений `review_logs` (каждая оценка карточки) и поле `profiles.study_plan` (лимиты дневного плана). Нужен для синхронизации прогресса дня между устройствами и в будущем — для алгоритма FSRS. ✅ применён |
| `20261126_video_lessons.sql` | Таблица `video_lessons` — видеоуроки (расшифровка, ссылка, разбор лексики), чтобы они были на всех устройствах. |

Пока миграция не применена, приложение работает как раньше: прогресс дня и видеоуроки хранятся в браузере.
